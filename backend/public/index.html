Browser Extension

The LinkedIn Intelligence Assistant extension sits beside LinkedIn in your browser. It reads only the page text you are already viewing, asks your local backend for a draft, and never sends, clicks, likes, or connects for you.

What it does

  • Reads visible text on the LinkedIn page you are viewing.
  • Sends that text to your local backend only, for drafting help.
  • Shows drafts in a side panel for you to copy by hand.

What it does not do

  • It never sends a message, connection request, like, or comment.
  • It never scrapes hidden data or profiles you have not opened.
  • It never contacts OpenRouter or LinkedIn directly. All AI calls go through your local backend.
  • It never holds your OpenRouter API key.

Install steps

  1. Open your browser extensions page and turn on Developer mode.
  2. Choose Load unpacked and select the extension folder inside linkedin-growth-agent.
  3. Open the extension popup and save the backend URL and token below.
  4. Open LinkedIn, then open the extension side panel to use it.

Compliance limits

Use it only on pages you open yourself, only for drafting, and only at a human pace. If the kill switch is on, all extension actions are disabled. Stop at any LinkedIn warning and report it. The extension is a drafting helper, not automation.

Extension backend settings

Copy these into the extension popup. The token below is your current session token, shown only in this browser tab.

The extension stores these only in its own storage on this device. Do not share the token.

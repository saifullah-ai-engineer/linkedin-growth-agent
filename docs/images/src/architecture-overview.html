DATA AND AI

SQLite

backend/data/app.db
13 tables, WAL mode
users, sessions, prospects, interactions, notes, goals, memory_items, drafts, recommendations, audit_log, model_config, error_log, app_settings

OpenRouter API

Chat completions endpoint
Key validated on /auth/key
429, timeout, or 5xx tries the next free model
Free tier: 50 free-model requests per day
425 models listed, 12 free

The OpenRouter API key lives in backend/.env (mode 0600) or the OPENROUTER_API_KEY environment variable. It is never logged and never returned to a client.

The app has no LinkedIn API access and imports no LinkedIn data. All numbers are records entered in the app.
